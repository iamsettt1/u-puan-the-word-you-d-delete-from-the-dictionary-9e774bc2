Entrants name the one word they would erase from the dictionary forever, and a judge model compares picks head to head until the funniest deletion wins. This entry picks "whatchamacallit" — the word you reach for when you have forgotten the name of a thing. Erase it and you can no longer even name the thing you cannot name.

```sh
python3 main.py
```
